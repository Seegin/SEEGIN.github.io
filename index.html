Robot systems · imitation learning

SEEGIN / liangxianzhong

I work on the engineering layer between a learning algorithm and a robot that actually moves. 我关注学习算法与真正运动起来的机器人之间，那一层常被忽略的系统工程。

I care less about making a model look clever in isolation than about what happens when it enters a system: where the data came from, what the action means, and how failure is recorded. 我不太关心让一个脱离系统的模型显得聪明。我更在意它进入系统以后： 数据从哪来、动作究竟代表什么，以及失败有没有被如实记录。

01Trace the whole path before tuning the model.先把整条链路跑通，再谈调参。
02Keep the evidence beside the claim.结论旁边放证据，数字旁边写口径。
03Leave the failed case in the report.失败案例不删，它定义能力边界。
